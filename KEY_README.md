# 按键处理模块

本模块实现了一个通用的 **多按键处理框架**，支持 **消抖、短按、长按、长按连续触发** 功能。

### ? 如是触摸按键 可不需要初始化 Key_Init() 不用编译 key_init.c 文件

---

## 一 开启普通按键初始化和按键扫描功能 (`key_config.h`)

| 宏定义         | 功能         | 默认值 |
| -------------- | ------------ | ------ |
| `IS_NOT_TOUCH` | 开启普通按键 | `0`    |

## 二 单个函数开启 (`key_config.h`)

| 宏定义                 | 功能                     | 默认值 |
| ---------------------- | ------------------------ | ------ |
| `DEBOUNCE_THRESHOLD`   | 防抖门限                 | `10`   |
| `LONG_PRESS_TICK`      | 长按时间阈值             | `250`  |
| `LONG_PRESS_AUTO_TICK` | 长按连续触发时间阈值     | `300`  |
| `AUTO_REPEAT_INTERVAL` | 长按连续触发时间间隙阈值 | `20`   |

## 三 KEYS_LIST 按键值对应表 (`key_config.h`)

| 按键值 (KEY_Code) | 短按返回值 | 长按返回值 | 长按标记说明 (1: 长按, 2: 长按自动触发, 0: 无长按功能) | 按键长按连续触发时间阈值 |
| ----------------- | ---------- | ---------- | ------------------------------------------------------ | ------------------------ |
| `0x01`            | 1          | 101        | 1                                                      | 0                        |
| `0x02`            | 2          | 102        | 2                                                      | 0                        |
| `0x04`            | 3          | 103        | 2                                                      | 0                        |
| `0x08`            | 4          | 104        | 0                                                      | 0                        |
| `0x10`            | 5          | 105        | 0                                                      | 0                        |
| `0x20`            | 6          | 106        | 0                                                      | 150                      |

## ? 调用实例

下面给出一个最小化的使用示例，展示如何在主程序中初始化按键、定时器扫描，以及获取按键事件：

```c
#include "key.h"


// ================= 主函数 =================
void main(void)
{
    unsigned char key_val;
    unsigned char key_raw;
    // 初始化
    Key_Init();

    while (1)
    {
        // 获取按键事件 或 第三方触摸按键事件
        key_raw = Key_ScanRaw();
        // 处理按键事件
        key_val = key_get(key_raw);
        if (key_val != 0)
        {
            switch (key_val)
            {
                case 1:   // 按键1 短按
                    break;
                case 101: // 按键1 长按
                    break;
                default:
                    break;
            }
        }

        // 其他业务逻辑...
    }
}
````

## ? 文件说明

- **key.h**

  - 模块头文件
  - 声明对外接口函数 `Key_Init()`、`Key_ScanRaw()`、`key_get(single)`

- **key.c**

  - 按键处理核心逻辑
  - 负责去抖、短按、长按判断，并缓存事件

- **key_init.c**

  - 按键 IO 硬件初始化示例（配置 GPIO 输入模式 + 上拉）

- **key_config.h**
  - 用户配置文件
  - 用于定义按键数量、引脚映射、消抖时间、长按时间等参数
